# Security

Report a vulnerability privately through [GitHub private vulnerability reporting](https://github.com/natefox2017/onetool/security/advisories/new). Do not post exploit details, secrets or private files in public issues.

Supported security fixes target the latest release and the main branch. Finder file creation must retain exclusive creation, path validation, symlink protection and authenticated request checks. Signing material belongs in repository Secrets or a local keychain and must never be committed.
