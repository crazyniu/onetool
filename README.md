# 1Tool

独立的原生 macOS 工具。应用名称 **1Tool**，包名 `com.shopkivoo.onetool`。

只保留以下功能：

- **超级右键**：移植原项目 Finder Sync 菜单与服务逻辑；新建模板、常用目录、复制路径、自动检测终端和编辑器、独立入口开关、隐藏文件显示切换。设置界面重新设计。
- **防止休眠**：30 分钟、1/2/4/8 小时、∞ 无限；系统、屏幕、磁盘与交流电下防系统休眠；按电源来源自动开启。
- **键盘背光**：滑块、快捷百分比、环境光自动调节。手动调节会关闭环境光自动调节。
- **多屏幕亮度**：逐屏控制系统亮度、DDC 硬件背光；可切换到软件调暗，退出时恢复原屏幕曲线。
- **默认输入法**：全局默认、每应用覆盖、跟随系统、可选关闭大写锁定。
- **状态栏图标**：默认使用原创扳手 Logo，沿用原项目 40 个图标选项与自定义符号名称逻辑，即时更换并保存；可显示防休眠状态点。左键打开随内容自适应高度的快捷面板，右键显示状态、定时、设置、图标和退出菜单。

外观采用原生 macOS 控件和语义背景；侧栏与内容使用不透明原生背景，macOS 26+ 主操作按钮使用 Liquid Glass，旧系统回退原生按钮。提供浅色/深色/自动主题、九种主色调（默认科技蓝）和登录启动。设置页与状态栏面板统一使用扁平蓝底白色竖直扳手图标，侧栏顶部居中展示。关闭窗口后应用继续在状态栏运行。

语言默认跟随系统，可在「外观与启动 / General → 语言 / Language」即时手动切换。支持英语、简体中文、繁体中文、日语、韩语、法语、德语和西班牙语；主界面、状态栏面板、应用自有菜单、Finder 操作及操作弹窗共用原生 String Catalog。系统授权和文件选择器的标准按钮由 macOS 本身提供。

## 构建与安装

需要 macOS 14+ 和完整 Xcode（包含 xcstringstool），无第三方包依赖。

```sh
./build.sh              # build/1Tool.app，包含 Finder 扩展与签名
./build.sh --install    # 安装到 /Applications/1Tool.app 并打开
./test.sh              # 核心逻辑和真实 IOPM 定时检查
./test.sh --hardware   # 额外检查输入法、键盘与屏幕；短暂调节后恢复
```

签名默认使用本机 Apple Development 身份，也可设置 `CODE_SIGN_IDENTITY`。没有身份时使用临时签名，Finder 扩展的系统启用受本机签名策略影响。当前提供本机完整功能开发构建，未作公证或发布。按用户最新安排，先完成功能，Mac App Store 沙盒与分发版本后续单独处理。

Xcode 可以打开 `Package.swift` 编辑、编译主应用；完整应用包和 Finder 扩展使用 `build.sh`。

## 首次使用

在“超级右键”中开启功能，并通过“管理扩展”允许 **1Tool Finder Actions**。应用需保持运行。首次访问桌面、文稿或外接磁盘，由 macOS 请求相应文件权限；在终端打开文件夹会请求自动化权限。隐藏文件切换沿用原项目：写 Finder 偏好并重新启动 Finder，无需辅助功能或 System Events。

外接显示器需要开启 DDC/CI。键盘和系统屏幕亮度通过动态检测的系统接口控制；不支持的硬件会显示原因或提供软件调暗。不要同时启用多个工具的自动输入法切换，以免规则相互覆盖。
