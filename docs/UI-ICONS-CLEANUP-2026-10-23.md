# 图标、主色与清理统计修正 · 2026-10-23

本记录覆盖“调整图标为苹果设置风格”对话的代码修正与独立验收。正式通用构建、安装和当前用户窗口最终验收由“清理电脑缓存”对话统一完成，见 [总验证记录](VALIDATION.md)。

## 已实现

- 侧栏采用纯色圆角底、居中白色 SF Symbol，所有功能入口都有颜色。后续按用户“过亮、符号不清”的反馈换成固定 sRGB 色板，避免深色模式把语义前景色提升成荧光色。当前采用 20pt 色块、5pt 连续圆角、13pt 中等字重符号，这些是实现参数。
- Logo 改为 48pt，在整个侧栏宽度内水平居中。移除左下角“正在保持唤醒”文字，防休眠状态及菜单功能保留。
- 默认蓝使用未经过自定义压暗的 macOS `systemBlue`；原生控件使用原生颜色 tint。中文颜色名统一为“蓝色”。现有石墨色选项仍按用户选择呈灰色。
- 主窗口默认尺寸改为 920×760，最低尺寸仍为 880×660。系统恢复的历史窗口尺寸不会被每次启动强制覆盖。
- 清理扫描分别记录已扫描位置实际占用和符合保护规则的可清理量。运行中应用仅统计占用，继续禁止清理；软链接和危险路径保护不变。缓存图按当前筛选的占用排序，列出前五项；应用行同时显示占用和可清理容量。
- 磁盘容量以同一次新查询读取并清除 URL 资源缓存，页面内每五秒更新，已用百分比保留一位小数，读取失败显示未知。进入页面、手动重扫、返回前台符合刷新条件和清理结束时更新相应数据；保留选择期间不自动扩大选择范围。
- 清理状态独立到 `CleanupModel.swift`，以隔离文件测试真实扫描与刷新过程。没有修改用户真实缓存用于验证。

## 验收边界

独立宿主使用当前真实 MainView、清理模型、引擎和页面，只延迟创建无关硬件/Finder服务，并使用独立偏好。它验证原生页面和本次交互，不代表已替换 `/Applications/1Tool.app`。

CUA 在后台操作宿主时窗口处于非活动状态，原生按钮和开关会显示系统失焦色；截图不作为活动窗口的开关主色 PASS。读取正式偏好时主色为 `graphite`，这能解释用户所见灰色。最终安装对话已接手按用户要求切回蓝色及活动控件验收，同时保持用户其他设置和防休眠会话。

920pt 是新的默认宽度设置；历史宽窗口的最终恢复/手动缩放需由安装对话在正式窗口完成。Homebrew 菜单与刷新按钮的对齐修正由包管理对话负责，不计入本记录的独立代码和测试范围。
