## 垃圾清理 — “清理电脑缓存”负责

- [ ] **UI-09 / P1：取消和部分失败仍显示成功完成。** `CleanupEngine.swift:189,208` 取消时 break 后返回普通结果，没有取消状态；`Cleanup.swift:241-259` 一律显示“Cleanup Complete”和勾号，失败详情被折叠。区分完成、部分完成、取消、失败，清楚列出已处理/跳过/失败数量和恢复去向；零处理且失败不能展示成功主状态。
- [ ] **UI-10 / P1：永久删除确认缺少具体范围。** `Cleanup.swift:289-294` 仅显示容量与数量，没有所选应用/目录；数量使用 selectedCandidates.count，却称作 categories。确认层列出本次具体应用、目录、数量和容量，长清单可滚动，保留醒目的永久/可恢复差异；确认时使用稳定的待执行选择快照。
- [ ] **UI-11 / P2：筛选后的空列表被描述成全盘已清理干净。** `Cleanup.swift:77,94-95` 在当前类别没有条目时显示 All Clear/No eligible old caches。区分“当前筛选无结果”和“已完成扫描且无可清理项”，前者提供清除筛选；存在跳过/不可访问范围时显示扫描不完整。
- [ ] **UI-12 / P1：不可读目录可能从结果消失，用户无法处理权限。** `CleanupEngine.swift:156,165` 对未能确认存在或未取得枚举器的路径直接 continue；其他读取失败只有 Some files could not be inspected。保留可区分的未扫描/权限不足状态与目录，接入权限页，保持保护策略。相关模块不得把权限受阻当作没有缓存。

- [ ] **UI-13 / P2：受保护应用仍提示“应用已选中”。** `Uninstall.swift:40-42` 只有无 issue 才选中程序包，但 `:120-124` 对所有 plan 都显示 The app is selected。按实际选中/保护状态显示文案及原因，受保护时明确不可卸载；底栏、复选框、说明必须一致。

- [ ] **UI-15 / P2：应用搜索无匹配时提示刷新或添加应用。** `Uninstall.swift:97-98,125-128` 把空库存与搜索无结果合并为 No Applications Found。区分首次加载、扫描失败、确无应用、搜索无匹配，搜索无匹配给清除查询入口。长应用清单当前是每项独立 ToolSection（`:130-154`），需要随新组件规范统一列表密度，保留真实应用图标和路径。

## Homebrew / npm — “增加 Homebrew 和 npm 包管理”负责

- [x] **UI-17 / P2：未检查更新与无更新混为一类。** `PackageManagement.swift:36,99` 刷新后 checkedAt 变 nil；`:127-129,221,227-228` 允许此时启用 Updates Only，并显示 No matching packages。未检查/检查失败时明确更新状态未知，提供检查更新入口；检查成功且没有更新才能显示无更新。刷新后的过期状态也应失效。
