# 权限与授权管理要求 · 2026-10-23

用户明确补充：“权限管理也没加进来吧，因为有些功能是需要申请权限的。”本项纳入当前 UI 改造，由主窗口对话负责统一入口及状态模型，卸载与包管理对话负责接入各自功能反馈。

## 页面及交互

- 提供容易找到的“权限管理”入口，采用用户选定的原生 macOS 组件。每行说明权限/系统授权名称、用途、受影响功能、当前状态和下一步操作。
- 区分已允许、未允许、尚未请求、系统设置中处理、无法确定、不适用，以及设备不支持。无法可靠查询的权限显示实际可观测状态，不能凭一个缓存布尔值显示“已授权”。
- 需要授权时，在对应功能页同步显示原因和去向。用户主动点击后才调用系统申请接口或打开对应系统设置；普通进入页面与刷新状态不触发一串授权请求。
- 从系统设置返回、应用重新激活时重新检测；提供手动刷新。打开设置不等于授权成功。授权后仍需用户重新发起清理、卸载或包操作。
- 区分 TCC 隐私权限、Finder 扩展启用、登录项批准、文件所有权/ACL 和命令行管理员交互；不同原因给出对应帮助。

## 按现有实现核对的接入范围

| 功能/系统项 | 当前证据 | 要求 |
| --- | --- | --- |
| Finder 扩展 | `RightClick.refreshStatus/openExtensionSettings` 已有系统状态和入口 | 复用现有查询，在权限管理和 Finder 页共用状态；启用后重新检测 |
| 自动化：Terminal / iTerm2 / Finder | `RightClick.openApplication` 使用 AppleScript；`automationGranted` 仅作不弹窗检查 | 按实际目标应用分项说明和检测；处理用户拒绝/撤销，提供授权或系统设置入口，保留原始错误详情 |
| 文件与文件夹访问 | Finder 文件创建、清理、卸载访问具体路径 | 对读取/写入失败保留错误类型与受影响目录，给出用户选择目录/系统设置等适用入口；不可将无权读取显示成无垃圾/无残留 |
| 完全磁盘访问 | 部分受系统保护路径可能受此限制；并非所有扫描都需要 | 按真实受阻路径和系统限制给出说明及手动设置入口。不能把普通文件权限错误都归因为缺少完全磁盘访问，也不能把成功读取某个文件等同于全盘授权 |
| 辅助功能及 Caps Lock | 当前 Caps Lock 使用 IOKit/HID，失败统一显示“检查辅助功能权限”；没有 AX 授权查询 | 先区分硬件、接口失败与实际授权不足；只有验证功能确实依赖该授权时才关联请求入口。输入法切换本身不能据此一概要求辅助功能或输入监听 |
| 登录启动 | 已有 `SMAppService` 状态及批准入口 | 共用现有状态；未批准与已启用分别显示 |
| Homebrew/npm 与管理员交互 | 当前子进程是非交互模式，`SUDO_ASKPASS=/usr/bin/false`；文档明确不提权 | 在界面解释需要管理员交互的操作未完成，给出适用的手动处理步骤与刷新/重试；区分 npm 前缀不可写、CLI 失败和隐私授权。沿用现有不提权边界 |
| 亮度、键盘背光、防休眠 | 当前主要为硬件/系统能力 API | 展示真实支持情况和失败原因；没有证据时不要求屏幕录制、输入监听等额外授权 |

## 验收 TODO

- [ ] 未授权首次使用：说明用途和受影响功能，拒绝后仍可使用其他功能。
- [ ] 授权或撤销后返回：状态更新，受影响按钮和提示同步更新。
- [ ] 读取部分目录失败：显示未扫描范围，不把结果包装为完整扫描。
- [ ] 无法判断/设备不支持/文件不可写：三个状态与“未授权”区分。
- [ ] 新权限入口适配浅深色、主色、Liquid Glass 开关、键盘操作和已有语言。
- [ ] 正式安装的应用签名身份与系统授权列表对应；开发探针的授权不能当成正式应用已授权。

## 官方资料

- [Apple：控制 macOS 中 App 对文件的访问](https://support.apple.com/en-gb/guide/security/secddd1d86a6/web)。
- [Apple：文件访问与完全磁盘访问](https://developer.apple.com/documentation/security/accessing-files-from-the-macos-app-sandbox)：完全磁盘访问需用户在系统设置中授予，不能由 entitlement 自动获得。宿主应用当前未开启 App Sandbox，仍需区分 TCC、文件系统权限及扩展沙盒。
- [AXIsProcessTrustedWithOptions](https://developer.apple.com/documentation/applicationservices/1459186-axisprocesstrustedwithoptions)：辅助功能信任查询与系统提示；是否适用于具体功能仍需按实际调用链验证。
